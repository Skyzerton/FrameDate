Инструмент для Unity Editor, в котором дизайнер задаёт и проверяет фреймдату приёмов файтинга Shadow Fight 4: Arena (SF4: Arena) — интервалы состояний, продвижение, hitbox и hurtbox, контакт, реакции цели, стены — и сразу видит результат в своём окне, без запуска игры.

Приёмы можно собирать вручную или импортировать прямо из файлов проекта игры: FrameDate сам читает настройки приёмов, анимации и модели героев, а игру открывать не нужно.
Состояние на 16.10.2026. Что готово, что в работе и что не поддержано — в разделе Статус.

Что умеет

**Своё окно, не playmode.** Вьюпорт, таймлайн и часы принадлежат окну; фреймдата дискретна и считается детерминированно (30 или 60 FPS).

**Таймлайн интервалов.** Два раздела — атакующий и цель, в каждом группы «Интервалы» (Attack, Uninterrupt, Blocking, Throwable…) и «Техника» (Movement, Hurtbox). Интервалы тянутся мышью, края меняют длину, пустое место создаёт новый, всё отменяется Undo.

**Продвижение.** Интервалы Movement с расстоянием и профилем (Linear, EaseIn, EaseOut, EaseInOut); несколько интервалов подряд дают неравномерное движение.

**Тела и удары.** Капсула hurtbox, пушбокс (невидимый, расталкивает бойцов по массам), hitbox атакующего. Интервал Hurtbox меняет размер тела по времени — приседание и пригибание.

**Контакт и реакции цели.** Контакт — первый кадр, на котором hitbox задевает hurtbox. Цель реагирует анимацией из каталога игры: попадание, крит или блок (подъём защиты и удар в блок).

**Арена.** Стены, камерные границы (предел расхождения), отдача от стены, ползунок сдвига старта для проверки приёма у стен.

**Единицы игры.** Все длины — в Units игры (1 Unit = 1 см), метрики арены вынесены в конфиг.

**Импорт из SFA.** Приёмы, серии ударов, скелет и капсулы, Idle, реакции цели; массовый перенос приёмов всех героев.

**Профили героев.** Ассет героя со списком всех его приёмов по категориям; выбор из списка в окне.


**Требования**

Unity 6000.2.14f1, Built-in Render Pipeline.
Для импорта из игры — локальная копия проекта SF4: Arena (sf-arena-client). FrameDate только читает её файлы и ничего в ней не меняет.

**Быстрый старт**

Откройте проект в Unity 6000.2.14f1.
Tools → FrameDate — откроется окно.
В тулбаре выберите приём: поле «Приём», либо кнопки Герой ▾ → Приёмы ▾ (по категориям), либо ◀ ▶ для перелистывания приёмов героя.
Двигайте ползунок кадров или нажмите ▶ Играть. Интервалы правятся на таймлайне, параметры — в инспекторе справа.

**Приёмы из игры (SFA)**

FrameDate читает файлы проекта игры сам, парсерами, повторяющими парсеры игры (хэши, числа Q44.20, сжатые кватернионы, детали моделей). Поза, капсулы, Idle и реакции трёх проверенных приёмов Линга совпадают с экспортёром, работающим на коде игры, на 0 Units.

**Импорт одного приёма**

Тулбар → Импорт из SFA… (или Tools → FrameDate SFA Import):
укажите папку проекта игры (например D:/_ACTIVE PROJECTS/SF4/sf-arena-client);
выберите файл настроек и приём; серию ударов можно собрать кнопкой «Собрать серию автоматически» или вручную (кадр перехода — по правилу игры, можно задать свой);
детали героя (скелет, броня, шлем, оружие), Idle цели, триггеры реакций — для Линга одной кнопкой «Пресет»;
Импорт в FrameDate.
Приём = серия ударов. Следующий удар берётся по Transitions и стартует с кадра перехода предыдущего (как в игре), поэтому базовый приём Линга — два слэша одним приёмом.


**Массовый перенос героев**

Там же: Перенести всех героев (работает в фоне, редактор не блокируется; есть «Остановить» и «Повторить неудачные»). Переносятся приёмы 30 героев из settings_arena_<герой>.yaml:
Assets/FrameDate/Moves/<Герой>/<Категория>/<приём>.asset
Assets/FrameDate/Moves/<Герой>/_Poses/<приём>_Pose.asset
Assets/FrameDate/Moves/<Герой>/<Герой>.asset            ← профиль героя
Assets/FrameDate/Reactions/<Герой>_Reactions.asset      ← каталог реакций героя
